# История, профиль и рейтинг

Все маршруты требуют `Authorization: Bearer <access_token>`.

- `GET /me` возвращает `{ "nickname": "...", "email": "...", "rating": 1200 }`.
- `GET /me/games?limit=20&offset=0` возвращает `{ "games": [...], "limit": 20, "offset": 0 }`. Лимит 1–100, по умолчанию 20. Партии отсортированы по `created_at DESC, id DESC`. В каждой записи есть `id`, `white_id`, `black_id`, `result` (`null` для активной партии), `ply`, `created_at`, `updated_at` и четыре поля рейтинга до и после партии. Поля рейтинга равны `null`, пока партия не закончена.
- `GET /me/games/:id` возвращает те же поля, текущий `fen` и массив `moves` по возрастанию `ply`. Каждый ход содержит `ply`, `uci`, `fen` после хода и `created_at`. Чужая партия возвращает 404.

Новый пользователь начинает с 1200. После завершения партии оба рейтинга меняются по стандартной формуле Эло с K=32 и округлением изменения до ближайшего целого. Результат, рейтинги и снимки в партии сохраняются одной транзакцией. Повторная попытка завершения возвращает ошибку и рейтинг не меняет. Партии, завершённые до миграции, остаются без снимков и не пересчитываются задним числом.

Ошибки возвращаются как `{ "error": "..." }`: 400 для неверных параметров, 401 без действующего токена, 404 для отсутствующего профиля или недоступной партии, 500 для сбоя хранения.
